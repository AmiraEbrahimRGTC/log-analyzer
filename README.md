# Log Analyzer - Cybersecurity Tool

## Overview
Log Analyzer is a Python-based tool that helps identify suspicious activities in server logs, such as multiple failed login attempts. This project is ideal for beginners interested in cybersecurity and learning how to analyze logs for potential threats.

## Features
- Parses server log files
- Detects repeated failed login attempts
- Highlights suspicious entries
- Simple command-line interface
